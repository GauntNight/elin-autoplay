# Tool notes: what each tool's domain taught us (moved out of elin-play at the 2026-10-30 review)

The tool index (purpose and usage, generated from the docstrings) is `tools/README.md`. This file keeps the notes
the runs attached to each tool: the numbers seen, the user's rules, the run that cost a lesson. Add a note here at a
close-out when a tool's domain taught something; a rule that every session needs goes in elin-play instead.
